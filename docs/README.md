# Shenyu Gateway 文档入口

仓库级文档状态和新线程阅读顺序以根目录 `DOCS_MAP.md` 为准。

## Architecture

- `architecture/SYSTEM_ZONES.md`：八个系统区和跨区桥梁。
- `architecture/REQUEST_CONTEXT.md`：请求、上下文、缓存、存储和归档参考。
- `architecture/MEMORY_ROOM.md`：Mem、Stars、Room 和 private capture 参考。
- `architecture/AUDIT_MATRIX.md`：风险、证据、修复记录和审计顺序。

## History

- `history/CLAUDE_REVIEW_FOLLOW_UP.md`：从 README 迁出的历史 code-review 执行清单。

不要把审查快照当作当前事实。代码、测试和 `DOCS_MAP.md` 标记的现行文档优先。
